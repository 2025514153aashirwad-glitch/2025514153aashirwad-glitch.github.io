Master Control
Prompt Book

How to use the free studio tools now installed alongside the film library, with ready-to-paste prompts for every stage, from brief to finished, checked, logged video.

For internal production use only. Not for publication. Everything listed here is free to use, with no purchase or subscription beyond the Claude Pro plan already in place.

1. How to use this book

  1. Open a session in the samatwam-films environment (the one with the studio tools). Paste the Master Control Prompt (section 4) first. It sets the rules, brand and quality bars for the whole session.
  2. Pick the prompts for the job from the chains in section 3 and paste them one at a time. Replace anything in {curly braces}. Leave everything else as written.
  3. Look before you approve. Every prompt ends by sending you stills or a contact sheet. Reply "approved" or say what to change. Nothing moves to the next stage without your yes.
  4. One film per session keeps usage low. Ask for the cheap checks (stills, a 10-second test) before the full render.
Usage tip. On Claude Pro, the expensive part is long back-and-forth, not rendering. One clear prompt with every decision filled in costs far less than five vague ones. The prompts here are written to be complete in one go.

3. Strategy: one pipeline, five stages

1 · BriefTreatment, beat sheet, timing, voice lines. P1
2 · LookThree style frames approved before any motion. P2
3 · BuildCanvas film, Blender hero shots, 3D, diagrams. P3–P10
4 · FinishVoice, music, grade, upscale, smoothing, captions. P11–P16
5 · Check & shipQA, delivery, logging. P18–P19

The core idea: hybrid films. The canvas library stays the backbone: it is fast, exact and on-brand. The new tools are added only where they make a visible difference.

  • Hero shots (the 2–4 moments a viewer remembers) go to Blender for real light and material.
  • Everything else stays code-drawn, then gets the same colour grade, so the two halves match.

Render cost on this machine sets the budget. At about 34 s per frame, spend Blender time only on shots of 10 seconds or less, and render them overnight.

4. The Master Control Prompt

Paste this first in every new session. It is long on purpose: it saves many corrections later.

MASTER CONTROL: SAMATWAM STUDIO SESSION

You are my film production team for Samatwam Org. I am Aish. I do not read
code. Explain everything in plain words, show me pictures, and ask me only
for decisions that are mine to make.

WORKSPACE
- Film library: /home/user/lemomo-ai/lemo-opuscar (read-only reference; build films in
  its films/ folder, deliver copies to my site repo).
- Site repo: /home/user/2025514153aashirwad-glitch.github.io, branch {branch name}.
  Deliver to films/{film-folder}/ and docs/.
- Studio tools: /home/user/tools. Blender (blender), web 3D libraries (tools/web),
  Real-ESRGAN (tools/esrgan), Poly Haven lighting and materials (tools/assets), Whisper
  models (tools/whisper), Indic Parler voice (tools/parler/bin/python). Manim,
  OpenColorIO and faster-whisper: tools/py/bin/python. Poly Haven assets are CC0.
  The environment's setup script reinstalls all of these on a fresh machine. If the
  film library is missing, clone github.com/lemomo-ai/lemo-opuscar and run its setup.
  Check that a tool runs before you assume it does.
- No GPU. Use 2 render workers (4 runs out of memory). WebGL needs
  LEMO_ANGLE=swiftshader. Put ffmpeg 7+ first on PATH before mux.sh.

BRAND (never break)
- Colours: ink #141414, muted #5A5A5A, line #E2E2E0, pass green #1F7A3A.
  Gold #B8933B only where something is earned, never decoration.
- Fonts: Space Grotesk (titles), Inter (body), JetBrains Mono (labels),
  Noto Sans Devanagari (Hindi).
- Official documents and on-screen text never mention Claude or AI.
- Do not touch Framer unless I ask.

QUALITY BARS (a film is not done until all pass)
1. Look: style frames approved by me before motion starts.
2. Motion: no stray lines, no pops, no objects passing through each other;
   every move eased; holds long enough to read (about 0.3 s per word on screen).
3. Text: every on-screen word readable at phone size; checked with readcheck.
4. Light: no unintended black or blown-white frames (blackdetect clean except
   intended darks, which you list).
5. Sound: narration about 10 dB over music; master at -14 LUFS (+/-1),
   true peak below -1 dBTP.
6. Voice: Whisper transcript matches the script; captions in sync within 0.15 s.
7. Delivery: mp4 + srt (English, plus Hindi if asked), poster.jpg, contact sheet,
   TREATMENT.md, CREDITS, build.sh, sources and fonts, committed and pushed.

WORKING RULES
- Stills first, then a 10 s test, then the full render. Show me each.
- Use tokens carefully: no long code dumps in chat, short status lines only.
- Never claim something works without checking it. Say plainly what failed.
- After each output: log it in Airtable (base appg8fTRMoVi3twdH, table Assets:
  Asset, Series "VIS", Link, Status Draft/Checked/Held, Notes; leave Tool empty).
- Do not create Linear issues unless I ask.

Reply "Ready" plus a one-line check that each studio tool runs. Then wait for my next prompt.

5. Feature prompts

P1 · Brief to treatment

Turns an idea into a timed plan. Approve this before anything is drawn.

Write the treatment for "{film title}" ({length} s, {fps} fps, {16:9 or 9:16}).
Audience: {schools / industry / partners}. One idea the viewer must leave with:
"{single sentence}". Mood: {three words}. Reference film from our series: {e.g. Film 05}.
Give me: a beat sheet with timestamps, the narration lines (short, spoken English,
about 2.4 words per second), on-screen text, where the gold is earned, which 2-4 shots
are hero shots (Blender candidates) and why, the sound idea, and the end card.
Save it as TREATMENT.md. Show it to me as a short table, not the whole file.

P2 · Look lock (style frames)

From the approved treatment, make 3 style frames at full resolution: the opening,
the main hero moment and the end card. Use the real fonts and brand colours. If a
hero shot is planned in Blender, make that frame in Blender with the real material
and lighting ({studio_small_09 / brown_photostudio_02 / kiara_1_dawn}).
Send the 3 frames side by side and list the 3 choices you made for each. Wait for my approval.

P3 · Canvas film build

Build "{film title}" in the film library following the page contract (DUR, render(t),
READY, EV, TEXTS) and our shared kit (common.js, samatwam_audio.py). Match the approved
style frames exactly. Then render stills at {list of 6-8 key times} and a contact sheet,
and run readcheck. Show me the contact sheet. Only after I approve, render the full
video at {fps} fps with 2 workers.

P4 · Blender hero shot (photoreal plate)

The main quality upgrade. Keep each shot at 10 s or less. Render overnight.

Make the hero shot "{shot name}" ({seconds} s, {fps} fps) in Blender with a Python
script saved next to the film (so it can be rebuilt).
- Objects: {e.g. brass plate with engraved mark, acrylic sheet, walnut base}.
- Materials: real physical materials. Use Poly Haven ones from /home/user/tools/assets
  where they fit ({wood_table_001 / marble_01 / rusty_metal_02}); fetch others free
  from Poly Haven or ambientCG if needed and note their CC0 licence in CREDITS.
- Light: HDRI {name} plus one key light; warm or cool to match the grade.
- Camera: {move, e.g. slow 20 degree orbit and push-in}; real depth of field focused on
  {subject}, f/{2.8}; motion blur on.
- Cycles on CPU, {64} samples, denoise on, full HD, Filmic/AgX view transform.
- Output: PNG sequence with transparent background if it will be composited.
First render 3 test frames (start, middle, end) at half resolution and show me. After
approval, render the full shot and tell me the time it took.

P5 · Composite Blender plates into the canvas film

Composite the approved Blender plate "{shot name}" into "{film title}" from {t0} s to
{t1} s. Load the PNG sequence frame-accurately inside render(t), match the canvas
grade and grain, add a soft contact shadow where it meets canvas elements, and cross
the seams with a {0.4} s dissolve or a cut on motion. Show stills at the entry, middle
and exit, before and after the grade match.

P6 · three.js scene with finishing effects

Add a three.js scene to "{film title}" for {what it shows}, from {t0} to {t1} s. Use
physical materials, the {HDRI} lighting map, and the postprocessing library for
bloom (subtle, highlights only), depth of field and film grain matching the canvas.
Drive every value from t (no real-time clock), so frames render exactly. Keep it light
enough for software rendering. Tell me the seconds per frame. Show 4 stills.

P7 · Path-traced poster or end card

Make the poster for "{film title}" at {3840x2160 or 2160x3840}: {composition}.
Render it in Blender Cycles at 512 samples (or three-gpu-pathtracer if the scene is
already in three.js), then finish the type in the canvas so the text stays crisp.
Give me 2 compositions to choose from at small size first.

P8 · Hand-eased camera choreography (Theatre.js)

For "{film title}", replace the formula camera with a Theatre.js timeline. Keys: {list,
e.g. 0 s wide, 6 s push to tablet, 14 s orbit left 30 degrees, 20 s settle}. Ease
each move so it starts gently, never stops dead and slightly overshoots only at
{moment}. Save the timeline as a JSON file that the film reads with t, and show me a
camera-path diagram plus 6 stills.

P9 · Diagram sequence (Manim)

Animate {diagram, e.g. "how a project moves from idea to award" as 5 steps} in Manim
using our fonts and colours (ink on paper, gold only on the final step). {seconds} s,
{fps} fps, transparent background, readable at phone size. Render a PNG sequence so
it can be composited into "{film title}" at {t0} s. Show me 4 stills.

P10 · Lottie sting

Play the Lottie file {path} inside "{film title}" at {t0} s, scaled to {size}, frame-
locked to t (no real-time playback). Recolour it to brand colours if it uses others.
If I have not given you a file, design a 2 s logo sting as a Lottie-style vector
animation in the canvas instead. Show 4 stills.

P11 · Narration voice

Record the narration for "{film title}" from vo/lines.json.
Voice: {Indian English (Indic Parler) / Hindi (Indic Parler) / British "George" (Kokoro)}.
For Indic Parler use the description: "{e.g. Rohit speaks in a calm, warm, slightly deep
voice at a moderate pace with very clear audio and no background noise}". Keep the
same description for every line so the voice stays consistent. Generate 2 takes of
line 1 first and send me both. After I pick, record all lines, trim silences, write
dur.json, and re-time the film's text to the real line lengths.
If Indic Parler is locked, tell me and use Kokoro George at speed 0.87.

P12 · Music and foley

Score "{film title}" with samatwam_audio.py: {instruments, e.g. santoor + tanpura + soft
tabla} at {BPM}, key {key}. Hit the beats at {list of event times}, with silence at
{times} for emphasis. Foley from the film's own materials ({e.g. paper, brass ticks}).
Duck the music under narration and master to -14 LUFS, true peak -1 dBTP. Report the
measured loudness and send a 20 s excerpt around the hero moment.

P13 · Captions and speech check

Make captions for "{film title}" from the narration (English{, plus Hindi}). Then run
the Whisper speech check on the final mix: transcribe it, compare it with the script
word by word, and measure caption timing. Report any mismatch over 0.15 s or any
misheard word, fix it, and re-check. Hindi captions get flagged for a native-speaker
check before release.

P14 · Colour grade (OpenColorIO)

Grade "{film title}" as one look across canvas frames and Blender plates. Look:
{e.g. "warm paper, deep but not crushed ink, gold that glows without clipping"}. Build
it as an OpenColorIO transform and export a .cube LUT, then apply it with ffmpeg at
mux time. Show me 3 before/after stills (dark, mid, bright scenes) and confirm no
brand colour moves by more than a just-noticeable amount (Delta E under 3) on flat areas.

P15 · Upscale (Real-ESRGAN)

Upscale {poster / these stills / the {t0}-{t1} s shot} 4x with Real-ESRGAN
(realesr-animevideov3 for graphics, realesrgan-x4plus for photoreal plates). Then
downscale to {target size} with a sharp filter. Compare 100% crops before and after
and tell me if the text or edges got worse. Text should be re-drawn on top, never upscaled.

P16 · Smoothing and motion blur

For "{film title}": add real motion blur to fast moves ({times}). Use Blender's motion
blur for plates, and in the canvas average {4} sub-frames per frame for the fast moves
only. For slow-motion at {t0}-{t1} s, use ffmpeg motion interpolation and check
for warping on edges and text. Show a still of the fastest moment before and after.

P17 · Reel template (9:16)

Make reel "{reel title}" ({15-30} s, 1080x1920, 30 fps) from {source film or brief}.
Hook in the first 1.5 s (movement + one bold word), one idea, end on the mark plus
{call to action}. Keep text inside the safe zone (top 250 px and bottom 420 px clear),
captions burned in large, sound designed for first-second impact and watchable
muted. Show me the first frame, the hook at 1.5 s and the end frame before rendering.

P18 · Quality check (run before anything ships)

Run the full quality check on "{film title}" against the 7 quality bars in the
Master Control. Do: contact sheet (24 frames), blackdetect and freeze detection,
loudness and true peak, readcheck on all text, Whisper speech check, caption sync,
file and folder check against the delivery list. Report a table with pass/fail per
bar and evidence. Fix every fail, then re-run only the failed checks.

P19 · Deliver and log

Deliver "{film title}": copy the deliverables to films/{folder}/ in my site repo,
commit with a clear message and push to {branch}. Log the video, poster and contact
sheet in Airtable (Assets, Series VIS, Status "{Checked}", Notes: what is still
open). Send me the mp4 and poster, plus a 3-line plain summary: what it is,
what passed, what still needs a human (logo, Hindi check, listening pass).

P20 · Upgrade or revise an existing film

Upgrade "{existing film, e.g. Film 03 Data Made Physical}". Keep the story, timing and
narration. Raise these shots: {list, or "pick the 2-3 that gain most from real light
and tell me why"}. Use P4/P6 for those shots, then P5, P14 and P18. Show me
before/after stills for each upgraded shot before re-rendering the full film.
Change nothing else without asking.

7. Limits to plan around

  • No GPU. Blender frames take about 34 s each, so keep photoreal shots short and render overnight. A GPU computer of your own (any recent NVIDIA card) would cut this by 10–30×. The same scripts run unchanged there.
  • The tools live in the cloud machine. A cloud machine is rebuilt between sessions, so a setup script in the samatwam-films environment reinstalls the tools automatically. The first session after a rebuild starts a few minutes later.
  • Indian voice needs your Hugging Face step (section 2). The Microsoft Prabhat voice cannot connect from the cloud.
  • Still needed from you: the real logo file, a native Hindi check of the captions, and one listening pass on each film's sound.
  • Licences. Poly Haven and ambientCG assets are CC0 (free for any use). Blender output belongs to you. Credit open tools in CREDITS.
